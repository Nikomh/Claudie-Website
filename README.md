# Claudia Thonet Agile Consulting — Website

Next.js 15 · React 19 · TypeScript · TailwindCSS v4

## Stack

- **Framework**: Next.js 15.5 (App Router)
- **Styling**: TailwindCSS v4 mit Custom Design Tokens
- **UI**: Radix UI (NavigationMenu, Dialog, Accordion, Tabs)
- **Icons**: Lucide React
- **Fonts**: Basier Circle (lokal)

## Entwicklung

```bash
npm install
npm run dev
```

## Hauptrouten

| Route | Beschreibung |
